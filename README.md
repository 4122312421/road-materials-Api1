# RoadMaterials API

Учебный проект по дисциплине «Инфраструктура и администрирование».

## Назначение

Сервис предназначен для сотрудников коммерческого отдела строительной
компании. Он позволит просматривать каталог строительных материалов
и рассчитывать стоимость материала и его доставки.

## Планируемые возможности

- Получение списка строительных материалов.
- Получение информации о материале по его идентификатору.
- Расчёт стоимости материала, доставки и общей стоимости заказа.

Дополнительно будут доступны служебные маршруты /health и /version.

## Модель расчёта

Стоимость материала = цена за тонну × масса в тоннах.

Стоимость доставки = тариф за тонно-километр × масса × расстояние.

Общая стоимость = стоимость материала + стоимость доставки.

Расстояние задаётся пользователем. Это упрощённая учебная модель:
она не учитывает обратный рейс, простой и другие дополнительные расходы.

## Учебные данные

Цены материалов и тарифы будут условными.
Проект не содержит реальных коммерческих данных компании.
